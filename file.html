1. Vision & Final Outcome

ما معنى BIT BY BIT؟

تعني خطوة صغيرة بعد خطوة صغيرة. نتعلم مفهومًا واحدًا، نطبقه، نلاحظ النتيجة، ثم نضيف عليه في اليوم التالي.

لماذا 1% كل يوم؟

لأن Automation ليست زرًا سحريًا. هي طريقة تفكير تتكون تدريجيًا: تحديد المشكلة، معرفة البيانات، اختيار نقطة البداية، ثم ربط الخطوات. خلال عشرة أيام لن نصبح خبراء، لكن سننتقل من عدم معرفة المفاهيم إلى بناء Workflow صغير يعمل.

النتيجة في Day 10

يستطيع المشارك أن:

  • يحدد مشكلة يدوية متكررة.
  • يرسم Workflow واضحًا.
  • يحدد Trigger وInput وAction.
  • يستخدم Make لبناء Scenario بسيط.
  • يضيف AI لمهمة مثل التصنيف أو التلخيص.
  • يربط Google Forms وGoogle Sheets.
  • يختبر النتيجة ويقرأ الأخطاء الأساسية.

3. Security Rules

  • لا تستخدم كلمات مرور حقيقية في أي تمرين.
  • لا تضع API keys داخل Screenshots أو Prompts.
  • استخدم بيانات وهمية بدل الأسماء والأرقام الحقيقية.
  • لا تدخل معلومات صحية أو مالية أو شخصية حساسة.
  • تذكّر أن AI قد يخطئ.
  • لا تستخدم Automation لاتخاذ قرارات عالية الخطورة دون مراجعة بشرية.

DAY 1 — WHAT IS AUTOMATION?

Theory first · No Make

الهدف

فهم Automation دون استخدام أدوات تقنية.

المفاهيم

  • Manual task: مهمة تنفذها بنفسك كل مرة.
  • Automated task: مهمة تنفذها الأداة بعد حدوث Trigger.
  • Trigger: بداية العملية.
  • Action: النتيجة أو الخطوة التالية.
New email
→
Check sender
→
Send notification

التطبيق العملي

  1. اكتب 3 مهام متكررة تقوم بها أسبوعيًا.
  2. اختر مهمة فيها بداية واضحة ونتيجة واضحة.
  3. اكتبها بصيغة: Trigger → Process → Action.

Mini Challenge

حوّل مهمة مثل “تنظيم طلبات التعلم” إلى Workflow من ثلاث خطوات.

Artifact اليوم: ثلاث مهام متكررة + Workflow واحد مكتوب.

Checklist

  • أستطيع شرح Automation.
  • حددت Trigger.
  • حددت Action.
  • كتبت Workflow واحدًا.
  • لم أستخدم Make بعد.

Organizer Pre-learning

20–40 دقيقة: افهمي الفرق بين Manual وAutomated، وجهزي مثالين من الحياة اليومية.

DAY 3 — AI FROM ZERO

الهدف

فهم دور AI داخل Automation دون رياضيات أو Training.

مفاهيم أساسية

  • AI: أنظمة تنفذ مهام تتطلب عادةً قدرًا من الفهم أو التحليل.
  • Generative AI: AI ينشئ نصًا أو أفكارًا أو مخرجات جديدة.
  • LLM: نموذج يتعامل مع اللغة ويتوقع مخرجات مناسبة للسياق.
  • ChatGPT: واجهة للمحادثة والتجربة والتعلم.

متى نستخدم Automation تقليدية؟

عندما تكون القاعدة واضحة، مثل: إذا وصل Form فأضف صفًا.

متى يكون AI مفيدًا؟

عندما تحتاج إلى فهم نص غير منظم، مثل التلخيص أو التصنيف أو استخراج المهام.

AI Taskمثال
Summarizationتحويل فقرة طويلة إلى نقاط.
Classificationتصنيف رسالة إلى Hardware أو Software.
Extractionاستخراج Task وDeadline.
Rewritingإعادة صياغة رسالة بلغة ألطف.
Generationاقتراح أفكار لمشروع.

التطبيق

أعطِ ChatGPT النص التالي:

“لدينا اجتماع لمراجعة فكرة المشروع يوم الخميس. يجب إرسال الملاحظات قبل الجمعة.”

اطلب منه استخراج:

  • Summary
  • Tasks
  • Deadlines

Mini Challenge

قارن بين تصنيف النص يدويًا وتصنيفه بالـAI. ما الذي أصبح أسرع؟ وما الذي يحتاج مراجعة؟

AI احتمالي وقد يخطئ؛ لا تتعامل مع مخرجاته كحقيقة مضمونة.

Organizer Pre-learning

حضّري نصًا قصيرًا وجرّبي عليه التلخيص والاستخراج والتصنيف.

ما هو Prompt؟

هو التعليمات والسياق والمدخلات التي نرسلها إلى AI. كلما كانت المهمة محددة، زادت فرصة الحصول على نتيجة مناسبة.

مثال سيئ

مثال أفضل

You are a clear and concise summarization assistant. Task: Summarize the input in 3 short bullet points. Rules: - Keep the meaning. - Do not invent information. - Use simple language. Input: [PASTE TEXT HERE] Output: - Point 1 - Point 2 - Point 3

Structured Output

نحتاج أحيانًا إلى نتيجة منظمة لأن Module لاحقًا يحتاج كل قيمة في حقل مستقل: Category، Topic، Level، Summary.

Mini Challenge

حسّن Prompt سيئًا، وأضف إليه Context وRules وOutput Format.

قالب جاهز

You are a helpful automation assistant. Context: [Explain the situation] Task: [Describe exactly what the AI should do] Input: [Insert the user data] Rules: - Do not invent information. - If the input is unclear, say "Unclear". - Keep the answer concise. Output format: Field 1: ... Field 2: ... Field 3: ...

12تأكد من إضافة Row جديد في Sheet.

DAY 7 — MAPPING, FILTERS & ROUTERS

Mapping

Mapping يعني أن تأخذ قيمة من Module سابق وتضعها في خانة Module لاحق. مثال: إجابة Form تذهب إلى User Request، وCategory الناتجة تذهب إلى عمود Category.

Filter

Filter يمنع أو يسمح بمرور البيانات بناءً على شرط. مثال: اسمح بالمرور إذا كانت Category تساوي Hardware.

Router يقسم Workflow إلى أكثر من مسار.

DAY 9 — TESTING & DEBUGGING

الهدف

Automation الجيدة ليست التي تعمل مرة واحدة فقط؛ بل التي نعرف كيف نختبرها ونفهم أين تتعطل.

اختبر هذه الحالات

  • Happy path: إدخال طبيعي.
  • Empty input: إدخال فارغ.
  • Unexpected input: نص غير متوقع.
  • Long input: نص طويل.
  • Wrong classification: تصنيف غير صحيح.
  • Connection failure: فشل الاتصال.
  • Missing field: حقل مفقود.
  • Bad output format: نتيجة غير منظمة.

Debugging Procedure

  1. حدد Module الذي فشل.
  2. اقرأ Input الذي وصل إليه.
  3. اقرأ Output الذي أعاده.
  4. افحص Mapping.
  5. افحص Filter أو Router.
  6. راجع تعليمات AI.
  7. أصلح خطوة واحدة فقط.
  8. اضغط Run once.
  9. أعد الاختبار.
AI probabilistic؛ قد يعطي نتيجة مختلفة أو غير صحيحة. استخدم تعليمات واضحة، Output منظمًا، Validation، ومراجعة بشرية عند الحاجة.

Testing Checklist

  • اختبرت Happy path.
  • اختبرت Input فارغًا.
  • اختبرت Input غامضًا.
  • فحصت Execution details.
  • تحققت من Mapping.
  • تحققت من Filter.
  • أعدت الاختبار بعد الإصلاح.

Organizer Pre-learning

عطّلي أو غيّري خطوة واحدة عمدًا، ثم اشرحي للمجموعة كيف عرفتِ مكان الخطأ.

  4. Define AI task.
  5. Define output.
  6. Build.
  7. Test.
  8. Debug.
  9. Improve.

  • AI task محدد.

8. Prompt Bank

A. Summarization

الهدف: تلخيص نص. يستخدم عندما: يكون النص أطول من الوقت المتاح لقراءته.

Summarize the text below in 3 concise bullet points. Keep the original meaning. Do not invent information. Text: [INSERT TEXT]

B. Classification

الهدف: وضع النص في فئة.

Classify the input into exactly one category: Hardware, Software, or Other. Return: Category: Reason: Input: [INSERT TEXT]

C. Extraction

الهدف: استخراج حقول من نص.

Extract the following fields from the text: Task: Deadline: Person: If a field is missing, write "Not provided". Do not invent information. Text: [INSERT TEXT]

D. Rewriting

الهدف: إعادة صياغة النص.

Rewrite the message in a friendly and professional tone. Keep it under 60 words. Preserve the meaning. Message: [INSERT TEXT]

E. Structured Output

Return only these fields: Category: Topic: Level: Summary: Use no extra headings. If information is unclear, write "Unclear".

F. Debugging Assistant

Help me debug this automation. Identify: 1. Where the problem may be. 2. What the input contains. 3. What the output contains. 4. One fix to test first. Do not assume missing information. Scenario description: [INSERT DESCRIPTION] Error or unexpected result: [INSERT ERROR]
